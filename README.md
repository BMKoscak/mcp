# MCP Nexus

MCP Nexus is a local Model Context Protocol hub for connecting language models,
tools, prompt templates, and observable JSON-RPC traffic through one web
workspace.

> **Status:** Phase 1 scaffold. Core MCP, API, UI, and publishing work will be
> delivered incrementally.

See [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) for the current design and
[`docs/DEVLOG.md`](docs/DEVLOG.md) for implementation history.
